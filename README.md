# Student Grading System 🎓

Hi everyone! This is my very first Python project. I built a simple console app to manage student marks, calculate grades automatically, and see class stats.

## What this program does

- **Add Student**: Enter name, roll number, and marks for Maths, Science, and English.
- **Auto Grading**: Automatically calculates total marks, percentage, and gives a letter grade.
- **View Records**: Shows a formatted list of all added students.
- **Search**: Search for any student using their roll number.
- **Class Stats**: Shows total students, overall class average, and who scored the highest.

## How grades are assigned

- **90%+** : A+
- **80% - 89%** : A
- **70% - 79%** : B
- **60% - 69%** : C
- **50% - 59%** : D
- **Below 50%** : Fail
